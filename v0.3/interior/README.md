## 영화에서 확인한 것 (형태만)
- **방**:
  - 뒷벽에 금빛 화면 3개가 있다(오른쪽 하나는 꺾인 벽 위).
  - 화면 아래를 따라 콘솔이 놓이고, 콘솔 아래 단에 밝은 띠가 있다.
  - 왼쪽 화면과 가운데 화면 사이에 문이 있다. 11098에서는 이 문 너머로 리브 복도가 보인다.
  - 길쭉한 육각 테이블은 몸체가 아래로 좁아진다.
  - 테이블 둘레는 한 단 낮은 구덩이이고, 구덩이 오른쪽 경계는 꺾인 벽과 나란한 사선이다.
- **복도**:
  - 단면은 밑동이 좁아지고 위가 안쪽으로 기운다.
  - 세로 리브가 반복되고, 리브 사이 두 높이에 밝은 직사각 조명이 있다.
  - 복도 끝 두꺼운 문틀 너머로 방이 보인다.
- **통로**: 11748에서 출입구 안으로 이어지는 것만 보인다(길이 UNKNOWN).

## 남은 문제
1. **복도 방향**: 11098에서는 복도가 왼쪽 뒤로 비스듬히 이어지는 것처럼 보인다. 각도를 재지 않았고, 비스듬히 두면 벽과의 접합부를 지어내야 해서 모델은 수직(가정)으로 두었다.
2. **방 맞은편(카메라 뒤쪽)**: 11882에서 복도 문틀 너머에도 화면과 콘솔이 보인다. 그쪽 벽에 화면이 더 있을 가능성이 있다(PROBABLE). 배치는 미확인이다.
3. **치수 정밀도**: 인물 축척 한 장 판독(자세·깊이 보정 없음)이라 ±25% 이상이다. 방 전체 폭, 화면 크기, 복도 높이는 특히 불확실하다.
4. **통로 단면**: 착륙장 출입구 크기 문제(처마 높이 대 인물 축척)가 정리될 때까지 미확정이다.
5. **복도 길이와 먼 끝**: 9 m는 모델링 중단 위치다.
