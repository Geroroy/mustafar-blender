## 0. 조사 방법과 범위

- **사이트 접근**:
  - 1차 시도에서는 이 환경의 네트워크 정책이 차단했다(프록시 403).
  - 사용자가 환경을 바꾼 뒤 2차 시도에서 갤러리 페이지와 이미지 CDN에 정상 접근했다(HTTP 200).
- **장면 찾기**:
  - 갤러리 **p62~p67**의 HTML에서 이미지 목록을 읽었다. 페이지당 180장, 총 1,080장이다.
  - 갤러리가 제공하는 **200 px 썸네일**만 받아 번호를 붙인 대조표(contact sheet)로 장면 순서를 확인했다.
  - 썸네일 약 20장은 이미지 서버가 HTTP 400을 돌려 비어 있다. 원인은 확인하지 않았다(관찰된 응답만 기록).
- **정밀 판독**:
  - 장면마다 필요한 프레임만 **3840×1600 원본**으로 받았다. 2차에 39장, 3차(측정·방 확인)에 18장을 더 받았다. 2장(11258, 11296)은 HTTP 400으로 받지 못했다.
  - 밝기를 올려 확대 판독했다. 아래 표의 "직접 판독"은 이 세션에서 원본을 보고 판단한 것이다.
- **받지 않은 것**:
  - 갤러리 전체(82페이지)는 받지 않았다.
  - p58~p61은 3장에 1장꼴(240장) 표본 썸네일만 보았다. p62~p67 밖의 나머지는 보지 않았다.
- **번호**: 갤러리 파일 번호다. 영화 프레임 번호나 타임코드가 아니다.
