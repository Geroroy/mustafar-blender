# CR-005 제출 — 낮은 상자 해석 정정 (2026-10-16)

v0.3 작업 사본. **영화 고증 승인이 아니다.** 바꾼 것은 낮은 상자(이전 이름 '계단 상자')뿐이다. 카메라는 바꾸지 않았다.
상세 변경표: `v0.3/CHANGES.md` 5차 정정.

## 정정 내용
- **철회**: 낮은 상자 안 반복 부재를 하강 계단으로 확정한 판정(이전 EVIDENCE C1 "하강 계단 VERIFIED", A-4 "하강 계단 확정").
  - 11246에서 보이는 것은 반복되는 밝은 경사 부재(톱니 모양)뿐이다.
  - 계단·환기·조명 어느 기능도 판정하지 않는다(**UNKNOWN**).
- **기본안에서 뺀 것**: 하강 발판 10단, 판·윗판 관통 구멍(바닥판 자르기 포함), 트렌치 높이로 내려가는 하부 연결.
  - 숨긴 가설 컬렉션 `Hypothesis_Stairwell_Descent`로 보존한다: `Hypothesis_Descent_Steps`, `Hypothesis_Deck_Opening`(철사틀).
  - 이 컬렉션은 렌더와 뷰포트에서 꺼져 있다. 비교 스크립트도 `Hypothesis_*`를 렌더하지 않는다.
- **영화에서 보이는 형태로 둔 것**(모두 판 윗면 위):
  - `Low_Box`: 4면 벽. 앞 끝(−Y) 벽을 더했다. 11246에서 윗테두리가 사방으로 닫혀 보이기 때문이다.
  - `Low_Box_Inner_Members`: 안쪽 반복 경사 부재 5개. 개수와 윗끝 간격 0.1 m는 후보다.
  - `Low_Box_Outer_Skin`: 바깥 경사면, 단이 진 윗테두리, 앞 끝 단, 사다리꼴 구획. 형상은 그대로다.
  - `Low_Box_Lit_Slots`: 밝은 세로 틈. 형상은 그대로다.
  - 판 아래와 상자 안 바닥 밑 구조는 만들지 않았다. 상자 안 바닥은 바닥판 윗면 그대로다.
- **그대로 둔 것**:
  - 상자 높이 1.2 m, 위치, 바깥 껍질 치수.
  - 출입구 높이(조명 중심 2.4 m), 바닥 배치, H1, 전체 치수: 모두 후보다.
  - R2 카메라와 처마: v0.2 기준안이다.
- **근거 문구 정정**:
  - 객체 basis가 기능 UNKNOWN을 명시한다.
  - `Corridor_Lower_Walkway`(v0.2 트렌치 자리 표시)의 근거에서 '내려가는 계단'을 지웠고, 상자와 연결하지 않는다.

## 영화 비교에서 본 점 (영화 이미지는 비공개 묶음)
- **11246(근사 카메라)**:
  - 영화에서는 안쪽 경사 부재의 밝은 면이 넓게 보인다. 모델(상자 1.2 m, 카메라 높이 1.7 m 근사)에서는 윗끝만 보인다.
  - 상자 높이나 카메라 높이 차이일 수 있지만 **판정하지 않았다**. 높이 후보와 카메라는 바꾸지 않았다.
  - 영화 윗테두리는 안쪽으로 기운 두꺼운 띠로 보인다. 긴 옆면은 사다리꼴과 역삼각 면이 번갈아 나온다. 모델에는 사다리꼴 구획만 있다(형태 후보, 미반영).
- **11615(R2 고정 카메라 겹침)**:
  - 영화는 상자 안쪽에 반복되는 밝은 세로 띠를 보여 준다.
  - 이 띠가 안쪽 벽의 틈(`Low_Box_Lit_Slots`)인지, 반복 부재의 밝은 면인지는 **UNKNOWN**이다. 둘 다 남겼다.
  - 상자 위치가 영화와 어긋난 점(이전 기록 86 px)은 그대로다.
- **11748·11726**: 상자 바깥 형태는 바뀌지 않았다. 출입구 판정(H1 후보)도 그대로다.

## CR-004 문구 제한 (같은 커밋에서 반영)
- '어떤 방향에서도 재현되지 않는다'로 읽지 않는다. 기록은 **"시험한 세 카메라 가설에서는 관찰된 구성을 재현하지 못했다"**이다.
- 시설 길이 축소 H2는 **미확정 대안**이다.
- 11206의 시설이 지상 결투 컷의 어느 면·구간에 해당하는지 대응이 확정되기 전에는 기존 시설을 짧게 줄이지 않는다.
- S-1~S-5와 H2의 형상 적용은 보류 중이다. 다음 단계에서 후보를 검토한다.
