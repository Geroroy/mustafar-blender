## 1. 대응점 정리

  - P1 테두리 끝 → P2 솟은 블록 시작 → P3 솟은 블록 끝 → P4 끝 단 윗면 → P5 바닥 접점

- **이전 큰 잔차의 점들은 같은 부위가 아니었다.**
  - 11726·11246에서 쓴 점은 P1(테두리 끝), 11748 이전 값은 P3 부근이었다.
  - 그런데 셋 모두 모델의 끝 벽 모서리 하나에 대응시켰다. 모델에는 솟은 블록이 없었다.

## 2. 끝 형태 국소 수정 (같은 카메라 전후: `endform/BA_end_*.png`)
- 주 테두리가 y −16.8에서 끝난다. 0.2 m 모따기로 0.15 m 솟은 끝 블록이 y −18.2까지 이어진다. 끝 단(윗면 상자 높이 × 0.75)과 경사 앞면을 지나 바닥 접점 y −19.4(기존 값)에 닿는다.
- 윤곽은 세 프레임에서 직접 보인다. **길이·높이는 후보값**이다: 후보 30개 중 끝 부위 오차가 가장 작은 값이지만, 기준안에서 두 주 프레임 카메라가 f 범위 끝에 붙어 근거가 약하다.
- 안쪽 부재 5개와 밝은 틈 5개는 짧아진 열린 구간 안에 다시 배치했다.
- 끝 부위 원시 오차(수정 후 형상으로 맞춘 카메라): P1·P2는 400~580 → 17~81 px가 됐다. P3는 106~152 px가 남는다.

- 기준안에서 대응을 바로잡자 출입구 쪽 점이 나빠졌다(11748 꼭대기 조명 31 → 128 px). 이전의 잘못된 끝 대응이 출입구 불일치를 가리고 있었다고 본다.
