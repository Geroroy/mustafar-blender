# MD_REMAKE_POC01 — Movie Duels 구조 참고 리메이크 시험본 (2026-10-16)

이 시험본은 Movie Duels 맵을 그대로 쓰지 않는다. 그 3D 구조를 참고해 영화와 우리 아이소메트릭 게임에 맞게 다시 만든 비교용이다.

- **보존**: 기존 A3c·A3d·A3e와 생성 코드는 그대로 두었다. 기존 맵은 비교 기준이고, 이 시험본으로 교체하지 않았다.
- **유지한 것**: 고정 게임 카메라, 직교 투영, 28.284 px/m, 렌더·스프라이트 출력, 보행·충돌·가림·스테이지 연결은 기존 파이프라인을 그대로 썼다. 전투·UI는 바꾸지 않았다.
- **보관 위치**: 모드 형상·질감은 제3자 자산이다. 그래서 그것이 들어간 `.blend`·게임 데이터·렌더 원본은 비공개 폴더(`research/CR-001_4k_evidence/_private/md_remake/`, git 제외)에만 두었다. 저장소에는 스크립트·설정·문서만 커밋했다. 게임 저장소(공개)에는 시험 데이터를 넣지 않았고, 확인할 때만 로컬에서 잠시 바꿔 넣고 되돌렸다.

## 참고 자료 우선순위(지시대로)
1. 실제 영화 프레임(이미 직접 확인한 것만): 78862·78853·78855·78837·11206·11246·11615·11712·11726·11748, R2·R6 측정
2. 사용자 요구: 베이 3칸, 각진 외곽, 플랫폼 확장 허용, 출입구 윤곽, 옆 통로
3. Movie Duels 추출 모델: duel_mustafar, duel_mus_both
4. 게임 제작 판단

## 1. 추출 모델 검증
**불러오기**
- 두 OBJ를 별도 참조 컬렉션(`REF_duel_mustafar`, `REF_duel_mus_both`)으로 불러왔다. 원본 좌표(Z 위)를 유지했고, 두 맵을 합치지 않았다.

**원본 맵에서 직접 확인한 것**
- 위치 엔티티(`target_location`): duel_mustafar의 "Landing Pad"(y 6360~7064)와 "Front Corridor"(y 3864~4120) 사이에 "Bridges"(y 4760~5656)가 있다. 그 밖에 "Private Landing Pad"·"Walkways"·"Control Room"·"Side Route" 등이 있다. 이름은 모드 제작자 표식이다.
- 플레이어 시작점은 z 24이고, JKA 플레이어 상자는 −24~+40이므로 바닥은 z 0이다.
- duel_mustafar 착륙장:
  - 판재 윗면 z 0, x −1280~960, y 6176~7584.
  - 바깥 테두리는 16 u 높이(x −1296~976, y 6160~7600). 판 아래면은 z −56, 아래로 받침 트러스가 있다.
  - 시설에서 먼 한 모서리가 576 u 절삭되어 있다.
  - 시설 쪽 변에는 판 바로 뒤(틈 없음)에 벽이 있고, 높이 240 u의 닫힌 A판 문 2개, 그 사이 기울어진 판 묶음, 앞에 격자 상자 3개·콘솔이 있다. 벽 윗선은 288 u.
- duel_mus_both 착륙장: 우주선이 있는 작은 판(크레넬레이션 기둥 테두리)이다. 판에 붙은 건물(틈 없음)에 아래가 넓고 위가 짧은 사다리꼴 입구, 기울어진 기둥 2개가 선 열린 칸, 건물 옆을 따라가는 ㄱ자 보행 띠가 있다. 건물 재질 대부분이 회색(질감 연결 안 됨)이다.

**복원 한계**
- 회색 재질, 잘린 검사 영역, 엔티티 회전·스크립트 이동, 외부 MD3 모델(조명 기구 등)은 원본 설계로 해석하지 않았다.
- breakingarm 연출은 재생하지 않았다.

**축척 보정(한 번)**
- 기준: 1 u = 1.8 m ÷ 64 u(JKA 플레이어 상자) = **0.028125 m**.
- 확인:
  - 모드 시설 벽 윗선 288 u는 8.1 m다. 영화 R2 처마(6.3~7.4 m)보다 약 10% 크다.
  - 모드 판 깊이 1440 u는 40.5 m다. R2·R6 범위(28~40 m)의 위쪽 끝이다.
  - 모드 문 240 u는 6.75 m다. 영화 문(조명 약 3 m)의 2배 이상이라 B로 분류했다.
- 불확실성: 약 ±10%. 원본 좌표를 미터로 보지 않았고, 카메라는 다시 계산하지 않았다.
