## 실제 출입 검증(게임 안, Playwright, 실제 충돌 반경 0.35)
결과 원본은 `renders/play_A3d/result.json`이다.

| 확인 | 결과 |
|---|---|
| 클릭으로 문틀 안 들어가기 → 판으로 나오기, 2회(출구 잠금) | 두 번 모두 됨(`inside door frame` true ×2, 나온 뒤 false) |
| 키로 곧게 들어갔다 나오기(W+D / S+A) | 들어가기 1.23초, 나오기 1.21초. 멈춤 없음 = 문에 걸리지 않음 |
| 틈 위 걷기 | 막힘. 열린 틈 쪽을 클릭하면 판 가장자리(gy 85.5)에서 멈춤 |
| 벽 통과 | 없음. 날개 벽 쪽을 클릭하면 걸을 수 있는 칸(문 안)에 머묾 |
| 이른 종료 | 없음. 잠금을 푼 뒤 문 앞 진입 바닥에서 `stage:exit`가 나오지 않음 |
| 종료 | 문틀 안(출구 칸)에 들어가면 `stage:exit` 발생 |
| 기존 확인 | 상자 충돌·뒤 가림·판 가장자리·전투 이벤트(`combatArea`, `combatTrigger`) 그대로 |

충돌 폭 측정값(0.125 m 칸):
- 문틀 안 1.88 m. A3c는 1.375 m였다.
- 상자 끝과 R 사이 통로 2.0 m.
- 진입 바닥 5.1 m.

검증 중 발견해 고친 문제가 하나 있다.
- **원인**: 문 어깨 높이(1.26 m)가 충돌 광선 높이(1.2 m)보다 높아졌다. 그래서 광선이 통로 옆벽 속에서 출발해 옆벽 밑면을 바닥으로 읽었고, 통로가 2.5 m로 넓게 잡혔다.
- **조치**: 광선 높이를 1.4 m로 올렸다. 벽을 투명하게 하거나 충돌을 끄지 않았다.
